# TFC_TimeNomina

Proyecto TFC – Sistema profesional de control horario con:

- Backend Odoo 19 dockerizado
- API personalizada para fichaje móvil
- Registro de coordenadas GPS
- Aplicación móvil React Native (en desarrollo)

## Estructura del proyecto

/backend → Contiene entorno docker y módulo Odoo  
/mobile-app → Aplicación móvil  
/docs → Documentación técnica  

## Tecnologías

- Odoo 19
- PostgreSQL 15
- Docker
- JSON-RPC
- React Native
- GitHub
